# BMI Calculator / VKİ Hesaplayıcı

## 🇬🇧 English

A simple **Body Mass Index (BMI)** calculator written in **C**.

This program calculates BMI using the user's weight and height and classifies the result according to standard BMI categories.

### Features

* Calculate Body Mass Index (BMI)
* Easy-to-use console interface
* Input validation
* BMI category classification
* Beginner-friendly C project

### BMI Formula

BMI = Weight (kg) / Height² (m)

### BMI Categories

| BMI            | Category          |
| -------------- | ----------------- |
| Below 18.5     | Underweight       |
| 18.5 – 24.9    | Normal Weight     |
| 25.0 – 29.9    | Overweight        |
| 30.0 – 34.9    | Obesity Class I   |
| 35.0 – 39.9    | Obesity Class II  |
| 40.0 and above | Obesity Class III |

### Compile

```bash
gcc bmi_calculator.c -o bmi_calculator
```

### Run

```bash
./bmi_calculator
```

## 🇹🇷 Türkçe

C dili ile yazılmış basit bir **Vücut Kitle İndeksi (VKİ / BMI)** hesaplayıcısıdır.

Program, kullanıcının boy ve kilosunu alır, VKİ değerini hesaplar ve sonucu standart BMI sınıflandırmasına göre gösterir.

### Özellikler

* VKİ (BMI) hesaplama
* Kullanımı kolay konsol arayüzü
* Hatalı giriş kontrolü
* Standart BMI kategorileri
* Yeni başlayanlar için uygun C projesi

### VKİ Formülü

VKİ = Kilo (kg) / Boy² (metre)

### VKİ Kategorileri

| VKİ           | Kategori          |
| ------------- | ----------------- |
| 18.5 altı     | Zayıf             |
| 18.5 – 24.9   | Normal            |
| 25.0 – 29.9   | Fazla Kilolu      |
| 30.0 – 34.9   | Obezite Sınıf I   |
| 35.0 – 39.9   | Obezite Sınıf II  |
| 40.0 ve üzeri | Obezite Sınıf III |

### Derleme

```bash
gcc vki_hesaplayici.c -o vki_hesaplayici
```

### Çalıştırma

```bash
./vki_hesaplayici
```
